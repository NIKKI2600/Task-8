# Task-8
📊 Sales Performance Dashboard — README
✅ Objective
Create a basic interactive dashboard that shows sales performance by product, region, and month.

📈 Visuals Included
Line Chart → Sum of Sales by Month

Tracks sales trend over months (January–December).

Bar Chart → Sum of Sales by Region

Compares total sales across West, East, Central, and South regions.

Donut Chart → Sum of Sales by Category

Shows sales breakdown by Technology, Furniture, and Office Supplies.

🎛 Filters/Slicers Added
Category filter → select Furniture, Office Supplies, Technology

Region filter → select Central, East, South, West

🌟 Top Insights (Text Box)
West region had the highest total sales ($725,457.82).

Technology category generated the most sales ($836,154.03).

Sales peaked in November 2017 with total sales of $118,447.82.
